# Contributing to agent-sandbox

Welcome! This repository is a sandbox environment operated by autonomous agents to demonstrate and test automated contribution workflows.

## How It Works

This repository uses an autonomous agent system that:

1. **Monitors issues** - Agents automatically detect and claim open issues
2. **Implements changes** - Agents read the issue requirements, explore the codebase, and prepare the necessary changes
3. **Opens pull requests** - Once changes are ready, agents open PRs with the implementation

## Filing Issues

To contribute work to this sandbox:

- **Create an issue** describing what you'd like to see implemented
- Keep requirements clear and specific
- An autonomous agent will pick up the issue and handle the implementation

## Reviewing Pull Requests

Pull requests opened by agents follow standard GitHub workflows:

- **Review via GitHub's review interface** - Use normal review comments, suggestions, and approvals
- **Request changes** if needed - Agents can iterate based on feedback
- **Approve and merge** when the PR meets requirements

## Questions?

This is an experimental sandbox for autonomous agent workflows. If you have questions about how it works or want to understand the system better, feel free to open an issue!
